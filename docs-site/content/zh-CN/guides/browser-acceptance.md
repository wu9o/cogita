# 浏览器验收

发布前应在真实浏览器中一起验证静态 HTML、运行时脚本、导航和搜索交互。使用独立的 `cogita-blog` 内容仓库，让检查覆盖真实消费者，而不是空的框架测试夹具。

## 启动预览

在 Cogita 仓库根目录运行：

```bash
pnpm run preview:lucid
```

默认地址是 `http://localhost:3034/`。要模拟 GitHub Pages 子路径，可在另一个终端运行：

```bash
BASE_PATH=/cogita-blog/ PORT=3035 pnpm run preview:lucid
```

子路径预览地址为 `http://localhost:3035/cogita-blog/`；`BASE_PATH` 会同时更新站点配置、内部链接和本地预览 URL。

## 验收清单

在根路径和子路径分别覆盖：

| 场景 | 验证内容 |
| --- | --- |
| 首页 | Hero、精选文章、最近文章和导航正常渲染 |
| 文章 | 从列表打开文章后，标题、正文、标签和阅读进度正常 |
| 搜索 | 搜索 `Git` 返回四条结果，且每条都能打开 |
| 标签 | `Git` 标签页显示预期文章 |
| 分类 | 分类页显示文章和子分类 |
| 归档 | 全部文章页和年度归档页可以打开 |
| 子路径 | 内部链接包含 `/cogita-blog/`，脚本和样式没有 404 |

每个场景完成后检查浏览器控制台，不应有运行时错误或资源加载警告。失败时记录 URL、控制台消息和复现步骤，再追踪构建输出与配置流转。

## 相关检查

浏览器验收前后运行：

```bash
pnpm run check:release
```

该命令覆盖包构建、兼容性矩阵、包边界、最小消费者、独立博客消费者和文档消费者；浏览器验收补充真实页面运行时与交互证据。
