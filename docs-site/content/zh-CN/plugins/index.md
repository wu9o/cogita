# 插件开发

Cogita 插件是接收增强站点配置的工厂函数，并参与 Rspress 构建。插件可以提供页面、虚拟模块、HTML 转换和构建检查，但不应该把主题布局或站点内容写死在插件里。

## 开始开发

1. 阅读[插件开发指南](./plugin-development.md)。
2. 阅读[插件 API 规范](./plugin-api-specification.md)。
3. 参考[文章元数据设计](./plugin-posts-frontmatter-design.md)了解完整的数据流。
4. 阅读准备新增能力对应的设计文档。

## 内置能力

内置生态覆盖内容索引、国际化、订阅、图片、站点地图、SEO、文章列表、搜索、分类、阅读进度、代码复制、评论、内容检查和外部内容源。每项能力的实现状态以对应包和设计文档为准。

插件通过公共能力标识和虚拟模块协作；主题负责消费这些稳定数据，站点负责决定具体配置。
