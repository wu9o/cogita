# Cogita 文档

Cogita 是一个主题驱动的静态站点框架。它把站点配置、主题、插件和内容索引拆分成可复用的包，适用于博客、项目手册和知识库。

## 推荐阅读路径

1. [开始使用](./getting-started.md)：创建并构建第一个站点。
2. [配置](./configuration.md)：了解站点、主题和插件选项。
3. [主题总览](./themes.md)：比较四种内置主题和对应 Demo。
4. [架构设计](./api/architecture-design.md)：理解构建期与运行时的数据流。
