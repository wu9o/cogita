# 架构设计

Cogita 将静态站点拆分为四个边界：

1. **Core**：加载配置、解析主题、注册插件并驱动 Rspress。
2. **Theme**：提供页面布局、全局样式和默认插件依赖。
3. **Plugin**：提供构建期数据处理、页面生成或运行时模块。
4. **Site**：持有文章、文档、图片和站点级配置。

~~~text
站点配置
  ↓
Cogita Core
  ├── 解析消费方安装的主题
  ├── 实例化主题插件
  └── 实例化站点插件
        ↓
      Rspress
        ↓
    静态 HTML / CSS / JS
~~~

## 为什么主题包属于站点项目

主题不是 Core 的内部注册表。站点直接安装主题包，Core 只通过包名解析它。这样新增主题不会要求修改 Core，也不会让所有使用者被迫安装不需要的主题。
