THEME-DRIVEN STATIC SITES

一套框架，构建博客、文档和知识库。

Cogita 把主题做成完整的内容生态：主题组织阅读体验，插件提供能力，站点只需要维护自己的内容和配置。

先看 Knowledge Demo ↗ 查看源码
ONE CONFIG · MANY CONTENT MODES

从选主题开始，而不是从拼插件开始。

每个官方主题都是一个独立消费者，能直接看到配置、内容和最终页面是如何连在一起的。

theme: '@cogita/theme-knowledge'
contentDir: 'content'

选择一个主题开始

四个独立 Demo，四种内容节奏

01 · REFERENCE

Docs

面向查阅的工程手册，把导航、正文和页面目录组织成清晰的阅读路径。

@cogita/theme-docs↗ 02 · FLOW

Lucid

面向持续写作的实践笔记，强调文章归档、标签、搜索和轻量阅读体验。

@cogita/theme-lucid↗ 03 · FEATURE

Editorial

面向专题叙事的编辑型刊物，用更强的标题层级和精选内容突出观点。

@cogita/theme-editorial↗ 04 · CONNECTION

Knowledge

面向长期积累的知识空间，把文章、手册、搜索和 JSON、Git 内容源放在一起回溯。

@cogita/theme-knowledge↗
主题是完整生态

主题不仅换颜色和布局，还能声明自己需要的插件，让内容体验保持一致。

插件按能力组合

文章、RSS、标签、SEO 和外部内容源都通过公开契约接入，逐步增强而不锁定站点。

真实消费者可验证

每个 Demo 都是独立站点项目，既能看最终页面，也能照着配置接入自己的仓库。

60 秒开始

先运行一个官方模板，再按自己的内容替换。完整配置、主题比较和部署说明都在在线手册中。

pnpm dlx @cogita/cli create my-site
cd my-site
pnpm dev
